# README screenshots

The four current README images were supplied by the project owner after customizing application/page colors. They include the native Windows titlebar. The original PNG bytes are preserved; these images were visually reviewed rather than regenerated by the automated capture script.

The start-screen image has no open book. All visible book text, titles and Library entries in the other three images belong to **A Reading Voyage**, original synthetic English demonstration prose by **GjøaReader Demo**. The text was checked against the [included sample FB2](../demo/A%20Reading%20Voyage.fb2), generated from the prose in scripts/readme-screenshots.mjs. To reproduce the reading material, use **+ → Browse files**, import the FB2, close the settled import queue and open the Library item. The sample is project-owned material under MIT; third-party application components retain their own notices.

- [Start screen](images/GjøaReader.png): project-owned ship artwork, with no document open.
- [Single Page](images/reading-light.png): page 3 of the demonstration book on custom green paper, with dark application chrome.
- [Facing Pages](images/reading-facing-dark.png): pages 2 and 3 on custom tan paper, with dark application chrome.
- [Custom palette editor](images/custom-colors.png): the built-in Tæt ThemeDesigner showing RGB, three harmony anchors, Surface/Border/State and light/dark controls; the demonstration book is visible behind the dialog.
- [Capture manifest and hashes](images/manifest.json).

Visual review found no personal file paths, emails, credentials, unrelated desktop windows or third-party publication text in these four images. PNG metadata contains no nonempty text fields or EXIF chunk. This is a review of the supplied images, not a new native-input or operating-system certification.

The optional script generates separate synthetic A Reading Voyage demonstrations, not exact replicas of the owner-supplied themes or native-window captures. After building release, run it outside the checkout:

```powershell
npm run screenshots:readme -- 'C:\Temp\GjoaReader-demo'
```

The script drives real application controls and also captures an annotation-tools view. Review its PNGs for layout and private information before copying selected images into docs/images and updating the manifest. Do not copy profiles, installed book editions, database files, logs or capture-result.json into source. The script closes only its own app process. Output is generated from real WebView pixels; no physical-input or whole-desktop screenshot claim is made.

Do not overwrite the owner-supplied PNGs when running the generator. Their hashes, dimensions and content-review status are recorded in images/manifest.json. Documentation preparation does not publish the project.
